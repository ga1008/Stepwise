# 步录 · Stepwise

适用于 **Windows 11 x64** 的本地桌面操作记录工具。截图、录屏、文字说明与文档在同一个项目目录中组织，可导出 Word、单文件 HTML、长图和 PDF 分享。

## 直接使用

从 [GitHub Releases](https://github.com/ga1008/Stepwise/releases/latest) 下载并解压 `Stepwise-1.3.0-Win11-x64-Setup.zip`。首次联网双击 **Prepare-Stepwise.cmd**，它会从原作者下载固定版本的 FFmpeg 8.1.2、校验 SHA-256，成功后自动启动程序。以后双击 **Stepwise.exe** 即可离线使用。请保留整个文件夹一起移动。

已有的本机完整包 `Stepwise-1.3.0-Win11-x64.zip` 已包含转换器，可直接双击 **Stepwise.exe**，不需要重新准备。

1. 填写项目名称、选择保存位置，点击“创建项目”。每次都会生成独立项目文件夹。
2. 点击相机图标截图：桌面冻结并变暗；拖动框选，单击全桌面。选定后进入标注窗口，确认后保存；取消则直接返回操作栏，不生成图片或步骤。
3. 点击录制圆点：选择区域后开始；再次点击红色停止按钮结束。操作栏右侧小箭头可选 `0 / 3 / 5 / 10 s`。
4. 在步骤浮窗中填写标题与说明，录制可选择 MP4 / GIF 或静音，点击“保存步骤”。截图确认标注、录制停止后，素材已保存在项目内；关闭步骤浮窗也会保存已填写文字。
5. 点击文档图标查看实时预览，可继续编辑、排序、移除步骤、修改项目名。点击预览页的“导出”，选择格式后开始导出；完成后可直接打开文件或所在文件夹。
6. 点击齿轮设置默认标注、音频、等待时间、录制导出规格、项目位置和快捷键。
7. 关闭操作栏即退出。正在录制时，会先停止并保存；处理期间请等待完成。

拖动操作栏左侧把手至屏幕边缘可自动收起，鼠标移近细柄即展开。系统托盘也可找回操作栏。操作栏默认保持置顶，点击普通按钮尽量不打断其他程序焦点；选区和填写说明时会主动接收输入。

| 快捷键 | 功能 |
| --- | --- |
| Ctrl + Alt + S | 立即截图，跳过默认等待 |
| Ctrl + Alt + R | 立即开始 / 停止录制，跳过默认等待 |
| Ctrl + Alt + P | 文档预览 |
| Ctrl + Alt + B | 显示操作栏 |
| Ctrl + Alt + O | 设置 |
| Ctrl + Enter | 保存当前步骤 |
| Esc | 取消选区 / 收起步骤表单 |

以上为默认全局快捷键，可在设置中逐项修改或清除。录入后自动检查 Windows 系统级占用和配置内重复；保存时再次申请注册，失败保留原配置。某些软件内部处理的快捷键无法通过 Windows 全局注册检测。启动时若被其他程序占用，会提示进入设置修改；操作栏和托盘按钮仍可用，不会悄悄换成另一个组合。设置窗口内暂时停用本程序的全局快捷键动作，避免录入组合时触发截图。

## 截图标注

截图上方的工具栏提供矩形框、圈选、画笔、实心箭头、文字、线宽、字号、颜色和确认/取消。

- **每一笔独立**：按下到松开形成一个笔迹；文字失去输入焦点后形成一个笔迹。无需管理图层。
- **选中与移动**：使用左侧指针工具，点击实际线条、箭头或文字，再拖动移动。框内空白、文字间隙不会挡住下层内容。绘图工具轻点已有笔迹也可切换到选择状态。
- **删除与撤销**：选中后按 Delete 或点击垃圾桶。Ctrl+Z 撤销，Ctrl+Y / Ctrl+Shift+Z 重做；一次拖动只撤销一次。
- **颜色与线宽**：只影响之后的新笔迹，已有内容不变。线宽默认 5 个原图像素。箭头始终朝向松开位置，其大小随长度变化，不受线宽控制。
- **中文与文字**：点击画面输入，Enter 换行，Ctrl+Enter 完成当前文字。字体内置完整 Noto Sans CJK SC，支持中英文与常用半全角标点；无需联网或向系统安装字体。
- **查看细节**：滚轮缩放，空格拖动或鼠标中键平移；底部可适应窗口或恢复 100%。屏幕缩放不改变最终图片分辨率。
- **确认与取消**：确认会合成所有笔迹再打开步骤表单；取消按钮或关闭标注窗口丢弃整张未确认截图，不占步骤编号。Esc 优先取消当前文字/手势或清除选择，再按可取消截图。

快捷工具：`V` 选择、`R` 矩形、`O` 圈选、`P` 画笔、`A` 箭头、`T` 文字。在画布上按 Ctrl+Enter 确认标注，文字输入中该组合仅结束当前文字。

确认时同时保存合成 PNG、`-original.png` 原始截图及 `.annotations.json` 笔迹记录。文档使用合成图，可由普通浏览器直接查看；笔迹记录为后续维护保留，本版标注窗口用于每次新截图，尚不提供历史图片重新标注入口。

## 默认配置与自动记忆

设置窗口按标注、采集、导出、工作区、快捷键分组。修改后点击保存立即应用；取消不改变已保存配置。恢复默认先更新窗口中的草稿，保存后才生效。当前项目的保存位置不会因修改默认项目位置而移动。

“根据操作更新记忆”默认开启。颜色、线宽、字号、常用标注工具、画布缩放方式、系统声音与麦克风开关、录制导出格式、MP4 静音选择和文档导出格式会自动保存。下一张截图、新项目和程序重启均会恢复；取消截图也不会撤销已经选择的偏好。关闭记忆后，操作中的临时调整不再改写默认值，仍可在设置窗口中明确保存新的默认配置。保存其他设置不会重置已记住的文档导出格式。

操作栏位置与贴边方向、最近选择的项目保存目录也会保留。显示器或分辨率变化时，操作栏会调整回可见工作区；原保存目录不可用时，启动页回退到“文档”。普通启动仍创建新项目，编辑已有步骤仍以该步骤实际保存的格式为准。

设置中的截图/录制默认等待时间会保留，作用于操作栏主按钮与托盘菜单；小箭头菜单的 `0 / 3 / 5 / 10 s` 只覆盖当次，立即截图/录像快捷键始终跳过等待。截图选区、当前笔迹、撤销历史、步骤标题和说明不会混入全局偏好。

偏好保存在 Windows 当前用户的 `%LOCALAPPDATA%\Stepwise\settings.json`（附上一次备份），不依赖项目目录或浏览器缓存，升级便携版后也可沿用。配置缺失或损坏时会安全使用备份或默认值。

## 音频与格式

- 默认同时捕获 Windows 默认输出设备与默认麦克风。音频菜单可提前分别关闭。
- 保存 MP4 时可选择静音；GIF 天生不含声音。默认 MP4 为 20 fps / 原尺寸，GIF 为 12 fps / 最大宽度 1440 像素。设置中可分别修改两种格式的帧率和最大宽度。
- MP4 支持 1–60 fps，GIF 支持 1–30 fps；最大宽度为 0 时保留原尺寸，其他宽度保持比例、不放大较小的原始画面。MP4 尺寸会对齐到编码所需的偶数。此处“大小”指像素尺寸，最终文件体积还取决于内容与时长。
- 公开包通过 `Prepare-Stepwise.cmd` 首次下载 FFmpeg 转换器；准备后无需系统级安装，媒体处理全部在本机完成。MP4 使用 H.264 + AAC，原始视频和两路音轨独立保留。
- 麦克风被系统静音或没有设备时会显示提示。需要录入人声时，请自行在 Windows 中检查默认麦克风、静音状态和应用权限。
- 原始视频按所选区域录制，帧率取两种导出默认帧率的较大值，默认 20 fps。长时间或高分辨率录制会增加磁盘占用；转换时不会删除原件。新规格用于后续导出，不会批量改写已有文档素材。

## 项目目录

```text
项目名称_时间_唯一编号/
├── project.json          项目清单、顺序与文字
├── project.json.bak      上次清单备份
├── document.html         实时生成的文档，引用 media 中的素材
├── media/
│   ├── images/           PNG 截图
│   ├── videos/           MP4 成品
│   └── gifs/             GIF 成品
├── recordings/           每次录屏的原始视频、双音轨和转换日志
├── exports/              分享成品；每次导出生成独立文件夹
│   └── 笔记名称-时间-格式-编号/  DOCX、单文件 HTML、PNG 或 PDF
├── drafts/               预留的草稿附件目录（文字直接暂存在清单）
├── logs/                 应用及恢复日志
└── .cache/               内置浏览器缓存
```

分享时推荐使用“导出”生成的成品文件；这些文件不依赖原项目目录。单张长图之外，内容较多时生成的多张 PNG 需要按编号一起分享。直接分享原项目的 **document.html** 时，仍须一起复制 **media 文件夹**，或打包整个项目。

移除步骤只会从文档中移除；项目清单保留移除记录，素材不删除。JSON 和 HTML 使用临时文件与替换提交；重新打开项目时可从备份恢复损坏的清单。

## 导出与分享

在文档预览页点击“导出”，选择格式，再点击“开始导出”。窗口显示进度和格式说明；HTML 会显示预计体积。完成后点击“打开文件”或“打开文件夹”，即可找到项目 `exports` 下本次独立的成品目录。多张长图通过“查看多个文件”打开文件夹。

| 格式 | 适合用途 | 图片、动图与视频 | 排版与文件 |
| --- | --- | --- | --- |
| Word `.docx` | 补充修改、正式交付 | 图片内嵌；GIF、视频使用第一帧，并标明静态预览 | 可编辑标题和正文；Letter 页面、页边距和页码 |
| 单文件 HTML `.html` | 离线阅读、分享完整操作过程 | 图片、GIF、MP4 全部以 Base64 内嵌；保留原始素材字节及音视频内容 | 自适应目录与正文，支持手机窄屏；点击图片放大、视频播放和保存素材 |
| 长图 `.png` | 直接发图、快速浏览 | GIF、视频使用第一帧，并标明静态预览 | 宽 1440 像素，每张最多高 12000 像素；优先按步骤分片，单步过长时继续分片 |
| PDF `.pdf` | 归档、固定版式和打印 | GIF、视频使用第一帧，并标明静态预览 | Letter 分页，保留可搜索正文 |

静态导出的图片按比例适配版心；用于 Word、PDF、长图和 HTML 首帧预览的图片最多为 **1600 × 2400 像素**，不会放大较小图片。原始截图、标注图、GIF 和 MP4 保持原样；HTML 仍嵌入完整原媒体。导出 Word 不要求本机安装 Office。

单文件 HTML 使用分块写入和按需解码：图片、GIF 进入视野后载入，视频点击播放后才解码，重复素材只嵌入一次。Base64 自身约增加 **33%** 体积，还会附加首帧预览与页面内容；窗口估计值并非精确文件大小。浏览器仍需读取整个 HTML 文件，长时间、高分辨率录像会增加打开时间和内存占用。文档的“打印 / PDF”按钮及 Ctrl+P 会先准备首帧，打印动态图像和视频时只使用静态预览。

导出开始前会暂存当前步骤的文字，随后按同一份项目快照生成整份文档。每次结果使用独立目录，不覆盖已有导出，不修改项目素材。处理中可点击“取消导出”，关闭窗口也会先取消；只有全部文件完成后才发布结果目录，取消或失败不会留下可误认为成品的半份文档。排错后可在同一窗口重试。

## 继续与恢复

正常启动默认创建新项目。需要继续编辑旧项目，点击启动页“继续已有项目”，选择原目录的 `project.json`；也可从命令行运行：

```powershell
.\Stepwise.exe --open "D:\操作记录\具体项目文件夹" --preview
```

录制中断后，在原项目预览中点击“恢复录制”。恢复依赖已经写入磁盘的内容，无法恢复断电前尚未写入的帧。先保留原始目录，不要删除 `recordings`。

## 运行环境

发行文件夹已包含 .NET 运行时，日常使用不需要 Python、Node.js 或管理员权限。公开包首次运行 `Prepare-Stepwise.cmd` 需要联网下载转换器；若下载失败，恢复网络后重新运行即可。转换器保存在程序目录，准备成功后可离线使用。内置预览使用 Windows 11 通常自带的 Microsoft Edge WebView2 Runtime。若精简系统删除了它，请从 [微软官方下载页](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Runtime。

受保护的视频、安全桌面、锁屏及某些独占全屏内容受 Windows 捕获机制限制。多显示器与负坐标已按虚拟桌面实现；不同设备、HDR 和混合缩放需要在对应硬件上检查。

## 开发与复现

源代码位于 `src/Stepwise`，使用 .NET 8 Windows Forms、WebView2 与 NAudio 2.2.1。安装 .NET 8 SDK 后运行：

```powershell
.\tools\Get-FFmpeg.ps1
.\tools\Get-AnnotationFont.ps1
.\build.ps1
```

构建结果位于 `dist/`。依赖锁定在项目文件中，媒体工具、字体来源、下载校验与许可证见 [第三方说明](../tools/THIRD-PARTY.md)。

`--self-test <目录>` 验证存储/转义/编号/备份恢复；`--media-test <目录>` 进行真实屏幕与音频录制及格式转换测试（会播放短测试音）。开发诊断 `--inspect-toolbar` 会关闭操作栏捕获排除，仅用于观察操作栏，日常使用不要添加此参数。

`--preferences-test <目录>` 检查默认配置、记忆开关、备份与跨进程写入；`--hotkey-test <目录>` 检查真实系统占用与注册事务；`--export-settings-test <目录>` 用合成媒体检查导出帧率、尺寸、音频和失败恢复。

`--note-export-test <目录>` 验证文档导出与结果文件；`node tests/standalone-html-test.cjs <单文件HTML> <原素材目录>` 检查内嵌媒体字节、CSP 和页面脚本交互。此处脚本测试不替代浏览器真实排版和视频播放验收。

前端与导出测试脚本位于 [GitHub 仓库的 tests 目录](https://github.com/ga1008/Stepwise/tree/main/tests)。可在构建后的程序目录中运行上述诊断参数，例如 `.\Stepwise.exe --note-export-test .\test-output`；测试会在指定目录生成报告和样本。测试屏幕录制时请先关闭含私人信息的窗口。公开包不包含开发期间的私人测试素材或内部验收报告。
