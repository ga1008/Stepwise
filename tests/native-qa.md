# 原生操作栏诊断验收

`--inspect-toolbar` 是开发验收参数。主程序将此参数传入 `ToolbarForm(inspectionMode: true)`，使原生窗口观察工具能够列出并截图操作栏。

该模式只改变窗口的系统呈现属性：显示任务栏入口、不设置 `WS_EX_TOOLWINDOW`，并将窗口捕获关联值设为 `WDA_NONE`（0）。操作栏的颜色、尺寸、图标、菜单、热键、拖动、贴边收缩和悬停展开继续使用正式模式的同一套代码；置顶和不主动激活行为也保留。该模式没有独立的演示布局。

默认不传参数，仍使用正式模式：不显示任务栏入口、使用工具窗口样式，并尝试设置 `WDA_EXCLUDEFROMCAPTURE`。`CaptureExclusionEnabled` 表示该排除捕获请求成功；诊断模式中此属性始终为 `false`，可通过 `InspectionMode` 区分主动诊断与系统设置失败。

## 诊断模式可以验证的内容

| 场景 | 观察点 |
| --- | --- |
| 默认展开 | 图标清晰、分组合理、状态行不溢出，窗口保持置顶 |
| 截图、录制箭头 | 两个独立菜单均提供 0、3 s、5 s、10 s |
| 音频菜单 | 系统声音和麦克风默认勾选，状态可分别切换 |
| 四边贴靠 | 拖到任意屏幕工作区边缘，移开指针后缩为细柄，悬停恢复 |
| 倒计时及选区 | 暂停自动隐藏后不会被边缘定时器意外展开或移动 |
| 找回操作栏 | 托盘双击可以找回；拔掉副屏后仍限制在现有工作区 |
| 焦点 | 显示、悬停展开、按钮点击尽量保留原程序焦点；截图选区和编辑器是主动输入操作 |
| 停止、退出 | 录制态停止按钮和热键可用，忙碌状态仍可发出退出请求 |

## 证据边界

**诊断模式会允许操作栏进入外部截图和录屏，因此不能用该模式的截图、录像或窗口检查结果证明“操作栏不入镜”。** 排除捕获必须另行使用未传 `--inspect-toolbar` 的正式模式进行真实截图、录制和结果检查，并记录 `CaptureExclusionEnabled` 的实际值。视觉验收证据与排除捕获证据应分开标注。

本文件描述验收方法与预期，不代表上述场景均已实际执行或通过。实际结果应写入 `verification` 下的验收记录。
